# 畫界台灣

**兩個相鄰縣市之間的界線被擦掉了——憑印象把它畫回來。**

隨機一題接一題。畫完告訴你平均偏了幾公里、把哪塊土地劃給了錯的縣市。

👉 **[開始玩](https://yo-chen.dev/games/taiwan-reborder/)**（鏡像：https://j0214ack.github.io/taiwan-reborder/）

玩法啟發自 [reborder.app](https://reborder.app)（Draw the missing border between neighbouring countries）的台灣縣市版。

## 玩法

1. 畫面上是兩個相鄰縣市合併成的一塊土地，共同界線被整段擦掉
2. 憑印象一筆畫出整條界線——從哪開始、到哪結束，也是題目的一部分
3. 畫不出來可開「提示」：顯示界線兩端 ●，從一個 ● 畫到另一個 ●

## 計分

一句話：**你的線平均偏離真實界線多遠，佔「這條界線本身的大小」的百分之幾**（v4，2026-09-09 Yo 定案）。

- 尺度＝界線外框的對角線，不是整張圖——人眼判斷的是「偏了這條線本身的幾成」；用整張圖當尺度時，短界線的題目（新竹宜蘭、台中花蓮）整條起伏只有一指寬，隨便畫都高分
- 「一指寬」寬容區＝**螢幕上的一指寬**（畫面對角線的 0.9%，界線很短時也不縮小；長界線題取界線大小的 1.5% 較大者）：每個取樣點的偏差先扣掉它、不足歸零再雙向平均——貼著畫幾乎不扣，超出的部分才用界線大小算，局部大歪照罰（v4.1，2026-09-09 Yo 桃園宜蘭實玩校準）
- 分數＝100 × 2^(−相對偏移／6%)——**每超出寬容區 6%，分數砍半**。兩個參數，皆可用 `?tol=&half=`（百分比）暫時覆寫供校準
- 平均偏離＝對稱最近距離（兩條線互相取樣最近點的平均，km）；超畫過端點的尾巴先裁掉不計（起訖偏移只顯示、不扣分）
- 沒畫到的界線段落會自然拉高平均偏離，所以不需要另設覆蓋率或端點懲罰
- 校準過程與對照圖：5 組縣市 × 8 種畫法（完美／手抖／接近／整條偏／畫一半／直線／翻面／離譜）逐輪比對，見 lab 專案紀錄
- 界線很短的題（桃園宜蘭、台中花蓮、新竹宜蘭只有十幾公里）：貼著畫就高分（直線也行——那個尺度下界線本來就近直線），畫明顯歪掉才重罰

## 細節

- 31 組可玩配對（台灣本島所有相鄰縣市，扣除兩組飛地：台北市╳新北市、嘉義市╳嘉義縣——它們的界線是封閉環，沒辦法「畫一條線」）
- 隨機出題，「下一題」隨時換；`?pair=南投縣,花蓮縣` 可直連指定配對（臺／台都通）；分享文字自帶同題連結，接得到的人畫同一題才比得起來
- 分享：純客戶端合成 1080×1350 成績卡 PNG（揭曉畫面＋分數＋偏差）。系統分享面板能「圖＋文」就一起送；只能擇一時**文字優先**；「複製成績圖」可複製到剪貼簿或下載。無資料庫、無上傳
- 純前端靜態站（`index.html`＋`app.js`），D3 與 topojson-client **自我託管**（`vendor/`，pin d3@7.9.0／topojson-client@3.1.0）——無後端、無 cookie、無第三方追蹤（正式站 yo-chen.dev 由 Cloudflare 注入無 cookie 的站台分析 beacon，CSP 僅放行它），並配 meta CSP
- 圖資：[taiwan-atlas](https://github.com/dkaoster/taiwan-atlas)（內政部縣市界 TopoJSON）

## 本機跑

```sh
python3 -m http.server 8000   # 開 http://localhost:8000
```

開發驗證鉤子：`?test=perfect|close|human|offset|half|chord|mirror|bulge`（完美描線／±4px 手抖／仿真人／整條偏移／前半對後半直線／直線亂猜／形狀翻面／離譜大彎；標題同時印新分與無寬容的舊分），可加 `&pair=A縣,B縣` 指定配對、`&mode=easy|free` 強制模式、`&off=<px>` 調偏移量、`&debug=1` 在標題印出計分內部數值、`&card=1` 疊出成績卡供目檢。
